# IncedenaryOS
An OS that is made by the user lightlybyte (@lightlybyt on TikTok), it is meant to be a basic daily-driver operating system with essential drivers like PS/2, USB, HDMI, Analog Audio. and possibly other drivers in the future like DisplayPort

# How to build
You build by running the file
buildkerneltoiso.bat

# How to clean directory of build
You run the batch file but instead
run the command: 
buildkerneltoiso.bat clean
